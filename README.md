# sms-text-blocks

Grok skill that turns chat output into brief, copy-ready iPhone Messages drafts.

## Install

Copy the skill folder into your Grok skills directory:

```bash
git clone https://github.com/jburum/sms-text-blocks.git
cp -a sms-text-blocks/.grok/skills/sms-text-blocks ~/.grok/skills/
```

Or drop `SKILL.md` and `references/` into:

`~/.grok/skills/sms-text-blocks/`

Start a new Grok session. Trigger with: sms this, make this textable, iMessage draft.

## Layout

```
.grok/skills/sms-text-blocks/
  SKILL.md
  references/examples.md
```
